# Система автоматического анализа электронных писем для выявления фишинговых угроз

Гибридная система детектирования фишинговых электронных писем, интегрирующая алгоритмы машинного обучения и эвристические правила детектирования. Система обеспечивает автономное функционирование с локальным развёртыванием всех компонентов без зависимости от внешних облачных сервисов.

## Описание системы

Система осуществляет автоматизированный анализ электронных писем в формате EML посредством последовательного применения следующих методов:

- Классификация на основе алгоритма машинного обучения Logistic Regression с векторизацией текстового содержимого методом TF-IDF
- Эвристический анализ на основе системы взвешенных правил для проверки механизмов аутентификации SPF/DKIM/DMARC, сопоставления доменов и выявления структурных аномалий
- Проверка репутации извлечённых доменов и IP-адресов по локальной базе данных индикаторов компрометации URLhaus и OpenPhish
- Автоматический перевод русскоязычных писем на английский язык посредством локальной модели Argos Translate для обеспечения корректной векторизации

Система формирует итоговый вердикт посредством взвешенной агрегации результатов машинного обучения и эвристического анализа с визуализацией детального отчёта через веб-интерфейс Streamlit.

## Требования к системе

- Python 3.8 или выше
- 8 ГБ оперативной памяти
- 2 ГБ свободного дискового пространства
- Подключение к сети Интернет для первоначальной загрузки языковых пакетов и индикаторов компрометации

## Установка и запуск системы

### 1. Клонирование репозитория

```bash
git clone <https://github.com/avseitsevad/eml-phishing-analyzer.git>
cd eml-phishing-analyzer
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Загрузка языковых пакетов NLTK

При первом запуске системы автоматически загружаются необходимые языковые пакеты NLTK (punkt, stopwords, wordnet).

### 4. Загрузка моделей машинного перевода Argos Translate

При первом запуске системы автоматически загружается языковая пара ru-en для модуля Argos Translate.

### 5. Запуск системы

Запуск системы осуществляется посредством выполнения скрипта инициализации:

```bash
python init.py
```

Скрипт последовательно выполняет следующие операции:
- Создание структуры базы данных SQLite для хранения индикаторов компрометации
- Загрузка актуальных данных из источников URLhaus и OpenPhish
- Запуск веб-интерфейса Streamlit

После запуска веб-интерфейс будет доступен по адресу `http://localhost:8501`.

## Инструкция по использованию

1. **Загрузка файла письма**: В веб-интерфейсе выберите файл в формате EML для загрузки

2. **Запуск анализа**: Нажмите кнопку «Начать анализ» для выполнения полного конвейера обработки письма.

3. **Просмотр результатов**: Система отображает итоговый вердикт с цветовой индикацией, агрегированную оценку риска, результаты проверки механизмов аутентификации, список извлечённых URL-адресов с репутационными индикаторами и перечень сработавших эвристических правил.

4. **Экспорт отчёта**: Результаты анализа могут быть экспортированы в форматах JSON или PDF для последующего документирования.

## Обновление базы индикаторов компрометации

Периодическое обновление локальной базы данных индикаторов компрометации обеспечивает актуальность проверок репутации. Обновление осуществляется автоматически при каждом запуске системы посредством скрипта `init.py`. Для ручного обновления без запуска веб-интерфейса выполните:

```bash
python -c "from scripts.update_threat_intel import update_all; update_all()"
```
